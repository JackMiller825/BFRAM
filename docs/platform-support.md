# Platform support

Checked against official docs in October 2026. A public URL is never publishing permission. This build can post only to Telegram, and only after the owner connects a bot and this server confirms that bot is an administrator of the destination chat. Every other platform stays an exportable draft until a real provider response exists. The app does not send DMs, replies, comments, mentions, joins, follows, or engagement.

| Platform | Publish in this build | Authorization required | What a public URL allows | Text / media limits used here | App cap | Official limits to honor | Notes |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Telegram | Yes, Bot API `sendMessage` only | Bot token in `TELEGRAM_BOT_TOKEN`. `getChat` + `getChatMember` must show the bot as `administrator` or `creator`. | Research record only. Post URLs and `t.me/+` invites are not destinations and are not joined. | 4,096 text, 1,024 caption. This path sends text only. | 4 posts / day / campaign, at least 1s between messages in a chat. | About 1 message/s in one chat, 20/min in a group, ~30/s bulk. HTTP 429 includes `retry_after`. [Bot API](https://core.telegram.org/bots/api), [bots FAQ](https://core.telegram.org/bots/faq#my-bot-is-hitting-limits). | No userbot, no paid flood skip, no messaging users who have not started the bot. |
| X | No. Drafts only. | User-context OAuth 2.0 with PKCE and `tweet.write` (media needs `media.write`) on an account the owner controls. | Profile URL is a reference, not a connection. | 280 characters unless the connected account’s own entitlements say otherwise. Threads are split. | 3 / day | Tier-specific. Honor `x-rate-limit-*` and HTTP 429. [Create Post](https://docs.x.com/x-api/posts/create-post). | Credentials, if present, are not used. Nothing is marked published. |
| YouTube | No. Drafts only. | OAuth scope `youtube.upload` (or broader `youtube`) for the owner’s channel. | Channel URL is a reference. | Title 100, description 5,000. | 1 / day | `videos.insert` default bucket is 100 calls/day. Unaudited API projects upload as private until Google’s audit. [videos.insert](https://developers.google.com/youtube/v3/docs/videos/insert). | Community posts are not available through this endpoint. |
| TikTok | No. Drafts only. | Content Posting API, `video.publish`, audited client for public posts. | Profile URL is a reference. | Caption 2,200. Success is the status endpoint, not init. [Content Posting](https://developers.tiktok.com/doc/content-posting-api-get-started). | |
| Instagram | No. Drafts only. | Professional account, `instagram_content_publish`, container then `media_publish`. | Profile URL is a reference. | Caption 2,200, up to 30 hashtags. | 2 / day | 24-hour cap (docs describe 100 on `media_publish`, with a lower cap on some surfaces). Read `content_publishing_limit` when connected. [Content publishing](https://developers.facebook.com/docs/instagram-platform/content-publishing). | Personal accounts cannot use this API. |
| Reddit | No. Drafts only. | OAuth `POST /api/submit` as the owner. Commercial use needs Reddit’s separate approval. | Subreddit URL is not permission to post. | Title 300. | 1 / day | Free OAuth tier is 100 queries/minute. [API](https://www.reddit.com/dev/api/), [Data API terms](https://redditinc.com/policies/data-api-terms). | |
| Discord | No. Drafts only. | Bot invited with Send Messages in that channel, or a webhook created there. | An invite link is not authorization. | 2,000 characters. | 4 / day | Global 50 requests/s plus stricter per-route limits. Honor 429 and `Retry-After`. [Rate limits](https://docs.discord.com/developers/topics/rate-limits). | |
| Websites and listing directories | No. | A paid placement still needs owner review, budget approval, and a sponsorship disclosure. | Prospect / reference only. | Export brief only. | None | Not a posting API. | The app does not fetch user-supplied sites. |

Uploads accepted for drafts: PNG, JPEG, GIF, WEBP, and MP4, up to 8 MB. SVG is rejected.
